CC: Mobile App Requirements (iOS)

Quick Reference Guide

| This Quick Reference Guide (QRG) shows the Recommended and Minimum technical requirements for using the PerfectServe Clinical Collaboration Mobile Application on iOS devices. |
| :---- |

**Recommended Requirements**

| Device/OS | Specifications |
| ----- | ----- |
| **iOS Version** | **iOS 17 and above** |

**Minimum Requirements**

| Device/OS | Specifications |
| ----- | ----- |
| **iOS Version** | **iOS 16 and above** |
| **\*Supported Devices (List [HERE](https://support.apple.com/en-ae/guide/iphone/iphe3fa5df43/16.0/ios/16.0))** | Any device that supports **iOS 16 or above** is supported by PerfectServe Clinical Collaboration. Apple retains a complete list of devices compatible with iOS 16 [here](https://support.apple.com/en-ae/guide/iphone/iphe3fa5df43/16.0/ios/16.0): |
| **Apple Watch** | **Series 4 and above** |

***\*NOTE**:* 

* *Due to security and performance, PerfectServe Clinical Collaboration only supports iOS 16.0 or above*
