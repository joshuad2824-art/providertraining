# Saving & Sharing Order Favorites in Cerner

**Audience:** Medical Staff
**System:** Cerner PowerChart

## Overview
Order favorites give end-users quick access to their most commonly used orders. This guide covers saving favorites, organizing them, Quick Orders, PowerPlan favorites, and using other providers' shared favorites.

## Saving individual order favorites
1. From the patient's chart, click **Add** on the **Orders** tab.
2. In the **Add Order** dialog, search and select the order.
3. Click **Done**.
4. Complete the **Order Entry Details** you want saved.
5. Right-click the order → **Add to Favorites**.
6. Click **OK** to save to the main favorites folder, or **Create Folder** for a new one.
7. Click **Favorites** in the Add Order window to verify.

## Organizing favorites
1. In the Add Order dialog, expand **Organize Favorites** (black arrow next to the star).
2. Use **Create Folder** to group orders (e.g., Lab, Rad, PRN, Pain Medications).
3. Drag and drop orders between folders.
4. Check **Sort favorites alphabetically** (by default they sort by the order added).
5. To re-sequence individually, select an item and use the up/down arrows on the right.

## Removing individual favorites
1. In the Add Order dialog, click **Favorites**.
2. Right-click an order → **Remove from Favorites**.
3. Click **Done**.

## Quick Orders
The **Quick Orders** page combines frequently used orders into a one-page catalog. To add a favorite folder: top-right → down arrow → **Add Folder** → scroll to the folder and click **Select**.

## Saving a PowerPlan favorite
PowerPlans group many orders into one set so you can add several orders for an admission or diagnosis at once.

1. In the **Orders** component, click **Add**.
2. In the **Find** box, type the PowerPlan name and press **Enter**.
3. Right-click the PowerPlan → **Add to Favorites** → **Done**. It lands in **My Favorite Plans**.

**To customize before saving:** find the PowerPlan, double-click it, then check/uncheck orders, **Add to Phase** for more orders, or right-click → **Modify**. When done, click **Save as My Favorite**, rename if desired, and **OK**.

## Modifying a saved PowerPlan favorite
From a provider workflow page, in the **New Order Entry** component:
1. Filter by **Mine** → **My Plan Favorites**.
2. Select the PowerPlan to modify → **Orders for Signature** → **Modify**.
3. Modify as needed → **Save as My Favorite**.
4. Rename if desired; select **Yes** to overwrite or **OK**.

## Using shared favorites
In the **New Order Entry** component:
1. Filter by **Shared** and type the clinician's name.
2. Select **My Plan Favorites** to view their saved PowerPlans.
3. Click the desired PowerPlan → **Orders for Signature** icon (top-right) to view details.
4. Click **Modify Order Details**, adjust orders if needed, then **Save as My Favorite**.
