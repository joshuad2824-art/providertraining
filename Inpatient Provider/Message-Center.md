# Message Center

**Audience:** Physicians
**System:** Cerner PowerChart

## Overview
Message Center is the screen each provider sees immediately on login. It contains the **Inbox**, where providers view and respond to messages, co-sign orders, and sign documents. Messages can be sent from Message Center or from within a patient's chart.

## Opening and reviewing Inbox items
1. In the **Inbox Summary**, click an Inbox folder (e.g., **General Message** or **Results**) or a subfolder (e.g., **Critical**). Matching notifications appear in the Inbox workspace.
   - **NOTE:** Select a range by clicking the first message, holding **Shift**, and clicking the last. Select individual messages by holding **Ctrl** as you click.
2. The selected message highlights blue on the left; its details display on the right.
3. If there are attachments, click the link to open and review the document.
4. Click **Reply** (sender only) or **Reply All** (sender and all recipients).
5. Compose the message.
6. Select any **Additional Message Center Options**.
7. To remove the existing message once sent, select the **Delete** check box.

## Approving, forwarding, and refusing orders
> You can select all orders at once and Forward, Approve, or Refuse them.

8. In Message Center, click **Orders** on the left.
9. Click **Select All** on the Orders toolbar.
10. With orders selected (highlighted blue), right-click the blue area and choose **Forward Only**, **Approve (no dose range checking)**, or **Refuse**.

**Refusing a single order:**
11. Right-click the order → **Refuse**.
12. In the Refuse window, choose a reason (options include: *I did not dictate this report; This document was already completed; This is an incomplete dictation; This is an incorrect order; This is not my order; This is not my patient*).
13. Add detail in **Comments** if needed, then click **OK** — the refusal goes to the **HIM Refusal Inbox** (HIM = Health Information Management, the medical-records department).

## Signing and co-signing documents
14. Double-click the message to open the document.
15. Select the **Modify** icon on the message toolbar.
16. The document opens for editing — you can type within the fields under each heading.
17. When finished, select **Sign / Submit** (bottom-right).

## Forwarding a document for review or signature
18. You can forward a document to another provider to review or sign.
19. At the bottom of the screen, the **Action Pane** automatically selects **Sign**.
20. Click **Other Forwarding Options** and use the dropdown to select **Review** or **Sign**.
    > **IMPORTANT:** Choosing **Review** or **Sign** asks the provider you're forwarding to, to review or sign it. This is often used by disciplines that require a signer, e.g., residents.
21. Search for the provider via the **binoculars** search box (type last name, first name).
22. Select **Next** to bypass the document until later. Once all required fields are filled, **OK & Close** and **OK & Next** become available. (If you don't select Additional Forward Actions, those two options are available by default.)
