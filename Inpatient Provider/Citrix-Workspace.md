# Citrix Workspace — Install

**Audience:** Clinicians
**Date:** Jun 17, 2022

## Overview
To run Cerner on a personal device, you need Citrix Workspace installed.

## Steps
1. Download Citrix Workspace: https://www.citrix.com/downloads/workspace-app/
   - **IMPORTANT:** Download the version that matches your operating system.
   - **Do not "Add Account."** You won't need to enter a URL or email address.
2. Go directly to the Cerner link: https://mvd.sjmc.org/vpn/index.html
