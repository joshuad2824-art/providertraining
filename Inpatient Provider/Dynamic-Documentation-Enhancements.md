# Dynamic Documentation Enhancements — Workspace Quick Guide

**Audience:** Providers
**Go-live date:** 11.20.2025
**Revision:** 10/24/25

## Overview
Introduces the new **Workspace** functionality within Cerner workflow pages. As of November 20, 2025, updated Dynamic Documentation and charting components live directly inside your workflow pages. (This enhancement does **not** include PowerNote.)

On go-live, the Workspace was automatically enabled for all providers. These documentation boxes now live **exclusively** within the Workspace and no longer appear separately in the workflow menu. *(A 6:19 walkthrough video accompanies the original.)*

## Workspace setup
1. To resize the Workspace view, select **Settings** (upper-right of the Workspace) → **Small**, **Medium**, or **Large**. Or drag the divider between the workflow components and the Workspace.
2. Use **Toggle Workspace** on the MPages ViewPoint toolbar to hide/show the Workspace pane (it appears to the right of the MPages components).
3. In **Settings**, put the Documentation Components (for DynDoc notes) first and arrange the component order. Click **Apply** to save.

## Pull-forward & template switching
You can now:
- Pull in either **Most Recent** or **My Last** documentation into designated components.
- Switch templates for the preferred view of active orders in the **Assessment and Plan** component.
- Look back up to **180 days**.

**Documentation components — pull-forward options:**
- **None** — pulls nothing forward (default for all components).
- **My Last** — pulls forward what the current user last charted for that patient in that component.
- **Most Recent** — pulls forward the most recent documentation by any user for that patient in that component.

**Assessment and Plan** can pull forward from both the diagnosis and the comment box, based on the selected template:
- **None** (default); **My Last Problem** / **Most Recent Problem**; **My Last Comment Box** / **Most Recent Comment Box**.
- Template behavior: **Standard** (A&P); **Diagnosis Only** (no orders pull in); **Inpatient** (active orders from last 12 hours); **Outpatient** (active orders from last 48 hours).

This lets providers reuse previously entered information, improving efficiency and continuity of care.
