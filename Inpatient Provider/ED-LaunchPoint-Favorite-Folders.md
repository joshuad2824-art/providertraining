# ED LaunchPoint Favorite Folders

**Audience:** Providers (ED)
**System:** Cerner FirstNet — LaunchPoint
**Go-live:** September 12, 2022

## Overview
To view orders from your favorite folders in LaunchPoint, each Favorites folder must be named per the **ED LaunchPoint (EDLP) naming convention**. Follow these steps to rename your favorites.

## Steps
1. In **Orders**, select the down arrow next to the star, then choose **Organize Favorites**.
   > The original screenshots show an incorrect naming convention — use the names below instead.
2. Select the folder to rename and choose **Rename**.
3. Retype the name to the EDLP convention:
   - Medications → **EDLP Meds**
   - Labs → **EDLP Lab**
   - EKG → **EDLP EKG**
   - Imaging → **EDLP Imaging**
   - Patient Care → **EDLP PatCare**
   - Consults → **EDLP Consults**
4. Select **Close**.

Once renamed, these folders appear in the ED LaunchPoint order favorites **above the line**.
