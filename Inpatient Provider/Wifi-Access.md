# Wi-Fi Access — Joining the AH-AIA Network

**Audience:** All Staff
**Network:** AH-AIA (use this for better Wi-Fi stability)

> **Key detail for every platform:** the username must be entered as `domain\username` (include the domain and backslash, or sign-in fails). The password is your AD (Active Directory) password.

## Android
1. Swipe down on the main screen and tap the settings gear.
2. Select **Connections** (may also appear as **Network & Internet** or **Network – WiFi**).
3. Select **WiFi** and make sure it's on.
4. Select the **AH-AIA** network.
5. If a **CA Certificate** dropdown appears, set it to **Don't Validate**.
6. Complete Identity and Password:
   - Identity: `domain\username`
   - Anonymous identity: leave blank
   - Password: your AD password

## iOS (iPhone/iPad)
1. Settings → **Wi-Fi**.
2. Make sure Wi-Fi is on (green), then choose **AH-AIA**.
3. Enter Username (`domain\username`) and Password.
4. Tap **Join**.
5. If prompted with certificate details, tap **Accept**.

## Windows Phone
1. Settings → **Wi-Fi**.
2. If AH-AIA already exists but won't connect, forget/delete it first. Remove old/legacy ministry networks too, if known.
3. Select **AH-AIA**, enter Username (`domain\username`) and password, tap **Done**.
4. When prompted, choose **Accept**.

## Mac
1. System Preferences → **Network** → **Wi-Fi** → select **AH-AIA**.
2. Enter Username (`domain\username`) and Password, then **Join**.
3. If prompted with certificate details, click **Accept**.

## Windows 10
1. Left-click the wireless icon (bottom-right) to list available networks.
2. Select **AH-AIA**.
3. Enter username as `DOMAIN\USERNAME` and your password. (Omitting `DOMAIN\` will block login.)

## Windows 7
1. Windows icon → **Control Panel** → **Network and Sharing Center**.
2. Top-left, click **Manage wireless networks** → **Add** → **Manually create a network profile**.
3. Network Name (SSID): **AH-AIA**; Security type: **WPA2-Enterprise**; Encryption: **AES**.
4. Check **Start this connection automatically**.
5. Use **Move Up** so AH-AIA sits at the top of the SSID list (the device connects to the top entry by default).
6. Double-click the AH-AIA SSID to verify settings.
7. On the Security screen → **Advanced settings** → check **Specify authentication mode** → set to **User or Computer authentication**.
