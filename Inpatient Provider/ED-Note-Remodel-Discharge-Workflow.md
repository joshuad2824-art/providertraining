# ED Note Remodel — Discharge Workflow

**Audience:** Emergency Room Providers
**System:** Cerner FirstNet
**Go-live:** 3/18/2026

## Overview
Guides providers through the discharge process using the new **Discharge Workflow** in the Emergency Department. The existing **Depart Process** stays available until further notice.

> **NOTE:** A **red star** marks required steps. A **green checkmark** appears when a step is complete.

## Completing the discharge
1. **Discharge Diagnosis** — select **Add as**, then add the problem. You must document a chronic problem or select **No Chronic Problem** to complete this section.
2. **Patient Education** — select, add, and modify if desired.
3. **Follow Up** — select the desired follow-up (it's added to the "Added Follow Ups" section). Click **Modify** to add details (when to follow up, address, free-text comments). A window opens from the right; you can save the template for future patients.
4. **Prescriptions** — search for and select the prescription, then complete the details.
5. **Discharge Order** — select the **+** on the order profile → **Discharge**. Modify details, then go to the order tray to sign and complete the prescriptions and discharge orders.
6. **Create Note.**
