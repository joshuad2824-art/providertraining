# AutoText Phrases — Create, Edit, Delete & Copy

**Audience:** Medical Staff
**System:** Cerner
**Date:** May 2, 2022

## Overview
AutoTexts are keyboard shortcuts in Cerner that quickly populate a note with information from the chart. The **Auto-Text Manager** lets you find, create, and manage personal and public phrases. It's available in Message Center, Physician Documentation, Workflow Documentation Components (HPI, ROS & PE), and Discharge Follow-Up.

> All AutoText phrases begin with a special character (`.`, `/`, `%`, `&`, etc.). "Public"/"Global" AutoTexts are available to everyone via the Auto-Text Manager.

## Using AutoText phrases
1. Click in a documentation field, then open the **Auto-Text Manager** tool.
2. In the **Manage Auto-Text** window, type the symbol tied to an AutoText (e.g., `%`). A list of all phrases under that symbol appears.
   - You must know which special character retrieves the phrase you want; if not, open the manager icon to browse what's available.
3. Double-click the one you want — it appears in your note.
4. Edit any of the pulled-in documentation as needed.

## Creating personal AutoTexts
1. Click in a documentation field and open the Auto-Text Manager.
2. On the **My Phrase** tab, click the blue **+** to add a phrase.
3. In **Abbreviation**, type a short trigger starting with a symbol (comma, dash, etc.).
   - **IMPORTANT:** Asterisk (`*`) is not allowed, and AutoTexts are **case-sensitive**. Example: `%CSROSALL`.
   - **TIP:** Using a symbol plus your initials makes personal phrases easier to find.
4. In **Description**, type the full name of your AutoText.
5. Build the content in the white space at the bottom:
   - Use the format bar for sections, headers, and text.
   - **Insert Templates/Tokens** to pull patient-specific data elements.
   - **Create Drop List** to add a dropdown.
   - **Use Blank Default** checkbox to stop the first dropdown item from auto-inserting.
6. Click **Save**.
7. Use it by typing the abbreviation in a documentation field.

> **NOTE:** To use AutoText in Message Center messages, the created AutoText content must be converted to **RTF**.

## Editing / duplicating / deleting personal AutoTexts
1. Open the Auto-Text tool and find the phrase in **My Phrases**.
2. Select it, then choose from the right side:
   - **Edit** — opens the window to make changes (including abbreviation and description fields).
   - **Duplicate** — copies it; be sure to update the abbreviation.
   - **Delete** — confirm **Yes/No** to remove it.

## Duplicating a public phrase for personal use
1. Open the Auto-Text tool → **Public Phrases** tab.
2. Find a phrase at the bottom left; use **Next** to page through.
3. When the detail appears on the right, click **Duplicate**.
4. Rename the abbreviation and description to your preference.
5. Edit the content as in "Creating personal AutoTexts."
6. It saves under **My Phrases**.

## Copy another provider's AutoText (Auto Text Copy Utility)
1. From the Organizer, select **Auto Text Copy Utility** (also in the **View** menu).
2. In the **search user** field, type the provider's name.
3. Click the AutoText and click **Copy**.
   - Long list: use the search field. Two: hold **Shift** and click. All: check **select all**.
4. In the copy window, change the abbreviation/description if desired.
5. Click **Log out** — required between copying AutoTexts.
